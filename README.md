# 오행 한 장

설치형 사주·궁합·오늘 미션 PWA. 접속: https://jilzu001.github.io/saju-pocket/

## 기능

- 한국 양력·음력·윤달 생일 입력, 출생 시간 모름 지원. 1962년 이후 대한민국 출생 대상.
- 개인 풀이 12장: 요약, 강점 개발, 보완 연습, 관계, 일·돈, 나이대, 세운, 대운, 월운, 일운, 오늘 미션, 계산 근거.
- 앞의 10개 주제와 궁합 3개 주제에 각각 상세 읽기 제공. 목차, 풀이 근거, 생활 사례와 실천 단계, 이전·다음 풀이 이동을 포함한다.
- 선택 MBTI 16유형 소통 힌트, 혈액형을 선택한 경우 자기 생각을 나누는 재미 질문. 두 정보는 사주 명식을 바꾸지 않는다.
- 연인·친구·동료 궁합: 일간 오행 관계와 일지 충, MBTI 소통 리듬을 독립적인 참고 요소로 사용. 성공 확률이나 성패 점수를 표시하지 않는다.
- 개인 미션 30종, 둘 미션 12종. 한국 날짜와 개인 식별값에 따른 순환 선택. 같은 날은 고정, 연속 30일(둘 12일) 중복 없음. 연속 방문 강요나 실패 벌점 없음.
- 새 사주 펼치기, 저장 목록의 사주 다시 보기·오늘 미션. 다시 보기는 현재 날짜로 갱신한다.
- 궁합의 두 사람은 각각 저장된 사주 불러오기 또는 새 입력을 선택한다. 저장+저장, 저장+신규, 신규+저장, 신규+신규를 지원한다.
- 대운: 선택한 남·여 기준과 년간으로 방향 계산, 월주에서 10년 단위 이동. 현재·다음 구간과 10개 구간 순서. 절입까지 일수/3, 정수 반올림(1~10세) 시작 나이 및 만 나이 기준. 미선택 시 추정하지 않으며 시간 모름은 정오 참고값, 절기 경계일의 시간 모름은 대운 보류.
- 세운은 입춘, 월운은 절입, 일운·미션은 한국시간 자정에 갱신한다. 각 운의 기회·관계·일·돈·주의·실천·다음 흐름을 제공한다. 현재 구간끼리 겹치는 주제도 읽는다.
- 최대 5명 선택 저장. 다음 실행은 최신 저장 인물의 오늘 미션부터. 완료 상태와 최근 60개 완료 기록 저장, 전체 삭제 지원.
- 생일 없는 요약 텍스트 공유. 설치 아이콘, standalone, 서비스워커 오프라인 실행.

## 계산과 해석

한국 음양력은 MIT `korean-lunar-calendar` 0.4.0. 시각별 절입 명식은 MIT `ssaju` 0.2.0. ssaju의 달력 변환은 사용하지 않고 한국 달력으로 변환한 양력을 넘긴다. 정월 초하루에서 ssaju solarToLunar의 잘못된 경계 반환을 확인했다.

한국 표준시, 1987·1988 서머타임, 경도 보정 없음, 자정 일주 변경. 절기 시각은 천문 근사값이며 정밀 만세력 인증이 아니다. 시간 모름은 시주를 제거하고 오행도 6글자만 집계. 절기 당일은 정오의 년주·월주 참고값임을 결과에 표시한다.

전통 상징을 바탕으로 한 자체 편집 해석이다. 상세 문장과 조합 규칙은 `reading-content.js`, `reading.js`, `fortune-content.js`, `fortune.js`에 분리한다. 해석 근거와 한계는 상세 문서 하단에 표시하며 외부 전문가 검수로 표시하지 않는다. 단순 생일 해시로 사주를 만들지 않는다. 날짜 해시는 미션 선택에만 쓴다. 나이대 제안은 전통 대운이 아니다. 올해 카드는 현재 한국시간의 입춘 전후를 반영한 년주를 사용한다. 학술적 성격 진단·미래 사건 예측을 주장하지 않는다.

## 개인정보

입력은 기기에서만 처리. 광고·외부 분석·API·폰트 요청 없음. 기기 저장 선택 시 localStorage에 기록. 공유에는 생일·시간·호칭을 넣지 않는다. 웹 호스팅 제공자의 접속 정보 처리는 별개다. 입력한 개인정보를 공개 저장소에 커밋하지 않는다.

## 개발

`python tools/build_site.py` 후 `_site` 정적 폴더 배포. GitHub Actions가 main push 시 자동 배포한다. 빌드에 npm 설치나 외부 서버가 필요 없다. 테스트: `node verification/check.cjs` (개발 환경의 Playwright 경로 사용). 기존 LottoDraw 등 다른 프로젝트는 변경하지 않는다.

날짜가 바뀌거나 절입 경계가 지나면 열린 결과와 상세 문서도 30초 이내 또는 앱 복귀 시 다시 생성한다. 대운은 정수 나이 구간을 쓰며 정밀 교운 날짜를 계산한 것으로 표시하지 않는다.

추가 검증: `node verification/reading-audit.mjs`는 해석 조합을, `node verification/detail-ui.cjs`는 상세 읽기·모바일·오프라인을, `node verification/upgrade.cjs`는 기존 저장 정보와 완료 기록을 유지한 PWA 업데이트를 확인한다. `node verification/profile-flows.cjs`는 저장·궁합 선택과 현재 나이를, `node verification/fortune-audit.mjs`는 대운 방향·구간·세운/월운/일운 경계, `node verification/fortune-ui.cjs`는 입력 보충·자동 갱신·오프라인을 확인한다. 브라우저 테스트는 `python -m http.server 8766 --directory _site` 실행 후 사용한다. 기존 `check.cjs`는 상위 `make_game_test` 폴더에서 실행한다.

PWA는 새 자산 전체를 캐시한 뒤 적용한다. 이후 업데이트는 설정의 ‘업데이트 확인 / 새 버전 적용’에서 사용자가 적용하며 입력 중 자동 재시작하지 않는다. 이 버튼이 없던 초기 버전에서 최초 업데이트할 때는 기존 탭·설치 앱을 모두 닫은 뒤 다시 연다.

모바일 기본 화면은 dvh와 안전 영역에 맞춘다. 아주 작은 높이·키보드·확대 글꼴 상황에는 스크롤을 허용하며 결과의 긴 근거 카드는 내부 스크롤 가능하다. 브라우저가 제공하는 viewport에서 시스템 영역을 중복 차감하지 않는다. 홈 화면 설치는 브라우저의 메뉴를 사용한다.

`CONTENT_PLAN.md`는 최초 초안이다. 실제 구현 범위와 계산 기준은 이 문서가 최신이다. 안내 문안은 `CONTENT_NOTICES.md`, 코드의 풀이 안내에 반영했다.

2026-10-11 콘텐츠 업데이트: 저장한 사주가 있으면 오늘의 한 줄과 연애·대인·일·돈을 먼저 표시한다. 운세 모음에서 달력 기준 월간 보고서(지난달 비교·절기 구분·다음 달 준비), 신년 보고서(분기·12개월·강점과 보완), 만남운, 생일 없이 고르는 12띠 운세를 제공한다. 대운 상세에는 현재·다음 구간을 포함한 10개 시간표를 표시한다. 궁합은 연인·부부·친구·동료이며 대화·감정·생활 리듬·시간과 돈을 따로 읽는다. 짝사랑·썸 콘텐츠는 포함하지 않는다. 모든 문장은 자체 콘텐츠이며 다른 사이트의 풀이를 복제하지 않는다.

오늘 미션은 일간과 일운의 관계에 연결하고 최근 60개를 보관해 같은 날의 완료 전후 문구를 유지한다. 기존 완료 미션도 유지한다. 메인 화면은 작은 휴대폰 크기에서 검증했고, 긴 보고서는 별도 상세창에서 읽는다. 신규 검증은 `node verification/experience-ui.cjs`이며 7개 콘텐츠 연결·12개월·12띠·부부 궁합·대운 시간표·모바일·오프라인을 확인한다.

모바일 가독성 개선: 본문 16px, 주요 버튼 16px와 최소 48px 터치 높이, 보조 설명 13px를 사용한다. 하단 기능은 테두리와 배경이 있는 버튼으로 표시하고 두 열로 배치한다. 작은 화면에서 글자를 축소하지 않으며 필요한 경우 오늘 화면·입력 영역에 세로 스크롤을 허용한다. 팝업 버튼과 포커스 테두리 사이에 여백을 확보했다. `node verification/mobile-legibility.cjs`는 320px~768px 반응형, 글자 크기·버튼 구분·터치 영역·팝업 겹침을 확인한다.
